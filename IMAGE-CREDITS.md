## Notes on reuse

- CC0 and public-domain images carry no attribution requirement. Credit is given anyway.
- CC BY and CC BY-SA images require attribution. For CC BY-SA the derivative must keep the
  same licence, so the cropped versions in `assets/img/` are offered under the same licence
  as their originals.
- If you replace an image with your own photograph, delete its row from this table.

## Replacing an image

Keep the same filename and a 4:3 aspect ratio (for example 900x675) so the layout does not
shift. Recommended export: JPEG, quality 75-80, progressive.
